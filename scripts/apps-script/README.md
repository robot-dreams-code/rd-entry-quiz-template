# Статистика квізу: налаштування за 5 хвилин

Квіз після кожного проходження надсилає **один анонімний рядок** у вашу Google-таблицю: дату, потік, результат, відсоток готовності, відсотки за темами й правильність кожної відповіді. Імен, пошти чи інших персональних даних немає.

У таблиці з'являться вкладки:
- **results** — по рядку на кожне проходження;
- **stats** — зведення: скільки пройшли, розподіл результатів і середні відсотки за потоками, найскладніші питання;
- **meta** — службова: назви тем і текст питань (для підписів у stats).

## Налаштування

1. Відкрийте Google-таблицю квізу → **Розширення → Apps Script**.
2. Видаліть усе в редакторі, вставте вміст файлу `Code.gs` з цієї папки, натисніть **Зберегти** (💾).
3. **Розгорнути → Нове розгортання** → тип **Вебзастосунок**:
   - Опис: `quiz stats`
   - Виконувати як: **Я**
   - Хто має доступ: **Усі** (anyone)
4. Натисніть **Розгорнути**, підтвердіть доступ своїм акаунтом і скопіюйте **URL вебзастосунку** (закінчується на `/exec`).
5. Перевірка: відкрийте цей URL у браузері — має з'явитися `ok`.
6. У репозиторії квізу в `config.js` вставте URL у поле `statsUrl`.
7. Пройдіть квіз сам — у таблиці з'явиться вкладка `results` з першим рядком.
8. В Apps Script виберіть функцію **setupStats** → **Виконати**. З'явиться вкладка `stats` з формулами. Далі вона оновлюється сама.

## Потоки

Додайте до посилання на квіз номер потоку: `…/?stream=2`. У статистиці потоки рахуються окремо. Без параметра рядок потрапить у групу «без потоку». Можна й буквено-цифрові назви: `?stream=2026-dec`.

Якщо квіз уже стоїть на лендингу з `?mode=landing`, проходження там позначаються як «лендинг» у колонці «Режим».

## Що в stats

- **Загалом:** кількість проходжень, середня готовність, частка «Можна стартувати».
- **За потоками:** проходження й середня готовність, розподіл трьох результатів, середній відсоток за кожною темою.
- **Питання:** частка правильних відповідей для кожного питання-перевірки. Найменші відсотки — кандидати на перегляд: або тема справді слабка в аудиторії, або саме питання сформульоване неоднозначно.

Після додавання нових тем чи питань запустіть `setupStats` ще раз — нові колонки підхопляться.

## Якщо не працює

- **У кроці 3 немає варіанта «Усі».** Корпоративний Google Workspace забороняє публікувати вебзастосунки поза доменом. Зверніться до адміністратора Workspace або використайте окремий акаунт для таблиці статистики.
- **Рядки не з'являються.** Перевірте, що в `config.js` URL закінчується на `/exec` (не `/dev`), і що після змін у `Code.gs` ви зробили **Розгорнути → Керувати розгортаннями → Редагувати → Нова версія**.
- **Демо в Claude** статистику не надсилає (вбудований перегляд блокує запити назовні) — перевіряйте на GitHub Pages або через HTML-файл у браузері.

## Важливо

- Дані анонімні, але технічно будь-хто, хто знає URL, може надіслати фейковий рядок. Для внутрішньої аналітики це некритично; для офіційної звітності враховуйте це.
- Студенти бачать примітку про анонімну статистику (ключ `disclaimer_stats` у вкладці settings) — вона з'являється автоматично, коли `statsUrl` заповнено.
